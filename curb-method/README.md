# The Curb Method → *Melbourne Cabinet Makers with Enthusiasm*

A working production system for generating 60-second episodes that use the actual
comedic and technical machinery of *Curb Your Enthusiasm*, transposed to a Melbourne
cabinet-making business.

## What's in here

| File | What it's for |
|---|---|
| `01-teardowns.md` | Beat-by-beat structural analysis of the three consensus-best episodes |
| `02-comedy-engine.md` | The eight mechanisms that make the show work, stated as rules |
| `03-production-craft.md` | How it's physically made — outline/improv, cameras, cutting, music |
| `04-dialogue-grammar.md` | How it's *spoken*: 14 rules for writing dialogue that reads as improvised |
| `05-series-bible.md` | *MCM* characters, wardrobe, vehicles, locations, running gags, voice |
| `06-sixty-second-format.md` | The 60-second beat clock, shot grammar, music spec, QA checklist |
| `07-generator.md` | Order of operations + the rule bank I draw from on request |
| `episodes/` | Three fully-produced example episodes with shot lists |

## A note on transcripts and footage

I didn't scrape transcripts or source footage, and I wouldn't distribute either —
they're HBO's. It also turns out not to be the constraint you'd think. What makes a
Curb scene land isn't the words; the words were improvised on the day and are
different in every take. What's reproducible is the **structure underneath** — the
outline, the trap geometry, the camera pair, the cutting rhythm, the way music is
withheld. That's what's documented here, at a level of detail that lets me build
episodes from it directly.

Where you want the reference material for your own study: the series is on HBO Max,
and on Binge and Foxtel in Australia. The three episodes torn down in `01` are
S2E7, S8E3 and S4E9.

## How to use it

Say **"make an episode of Melbourne Cabinet Makers about X"** and I run `07-generator.md`:
pick rule → pick victim → pick seed → build the collision → write Scene C first →
work backwards → cut to word count → run the 25-point QA checklist. Output is a
shooting script with timecodes, a shot list, and continuity notes.

If you don't give me an X, I pull from the rule bank.
